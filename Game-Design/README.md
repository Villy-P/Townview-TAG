# Game-Design

A collection of projects I did in my Game Design Class during my Sophomore year of High School

## Projects

### [Engine](./Engine/)

Basic Engine for Jumpstarting a Java Game
Used it to make a basic version of pong that you can play with someone else

### [Platformer](./Platformer/)

Simple 2D platformer with multiple levels written in Java.
Levels are loaded in as text files, and there are different enemy types.

### [OpenGL](./OpenGL/)

Basic Engine for bootstrapping a quick OpenGL Project
Includes shader support along with support for making meshes.

### [Terrain Generation](./Terrain-Generation/)

Basic Test to see how Perlin Noise would work within OpenGL

### [2nd Game](./2nd%20Game/)

OpenGL game where you would wander around a procedurally generated terrain.
Implemented model loading, tree instancing, and more
Quit because shadows are hard

### [The Wanderer](./The-Wanderer/)

Unity Game that takes the ideo of the 2nd Game and updates it
Support for multiple biomes along with more types of foliage per biome.
